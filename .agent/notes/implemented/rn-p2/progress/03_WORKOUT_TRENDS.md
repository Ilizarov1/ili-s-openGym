# 03 训练趋势

## 需求

用户在统计页按时间范围查看训练次数、训练量和单动作表现。训练次数按场统计，单动作趋势给出每场的完成组最佳实记指标，点选可看原训练。

## 实现设计

- [StatsScreen](../../../mobile-rn/src/screens/StatsScreen.tsx) 复用现有 `history` 投影和 `sessionVolume`。按 [`workoutDay` 与 `workoutAt`](../../../frontend/src/lib/history.js) 判定本地日期，使用 [`weekStartOf` 与 `weekKey`](../../../frontend/src/lib/format.js) 聚合周桶。时间范围沿用上游 30、90、365 天和全部，按本地自然日筛选后再聚合；范围内空周补零。
- 图表使用现有 RN 设计 tokens，按当前单位换算待补传记录，复用正式组、热身计入设置和高级组训练量算法。单动作表现与 [PR](01_PERSONAL_RECORDS.md) 共用模式、完成组和单位规则，图上按训练时间展示，统计结果从数据实时派生。

## 执行步骤

1. 写可注入当前时间的汇总逻辑，明确日期边界、空周、同日多场、训练量单位和重复数据的处理，再接入统计卡及单动作曲线。
2. 用 fixture 执行下表。截图记录范围切换与来源组，独立 API 回读确认编辑、删除和补传后的趋势。

## 验收目标

| 编号 | 前置条件 | 操作 | 通过标准 |
| --- | --- | --- | --- |
| 1 | 一周内同日完成两场，分别为 100 kg×3 和 50 kg×4；下一周无记录 | 查看按周汇总 | 第一周 2 场、500 kg；下一周 0 场、0 kg |
| 2 | 在周日 23:55、周一 00:05 各有一场训练，另有一场在所选范围首日前一天 | 使用本地周一开头，切换范围和周起始日 | 两场按当地日期落入正确周；范围外记录不计入；周日开头重新分桶 |
| 3 | 一条 1220 kg 递减组训练、一条 720 kg 休息暂停组训练，另有未参与默认计算的热身 | 查看训练量，切换配置包含热身后复查 | 默认合计 1940 kg，开启时按实际热身量增加；短休分段未重复计入 |
| 4 | 同一动作两场训练，最佳完成组为 80 kg 和 95 kg，另一次只做了热身 | 选动作并点选 95 kg 数据点 | 图上有两场表现点，来源是实际 95 kg 的训练，热身场没有表现点 |
| 5 | 有一条同时出现在同步回包与待补传列表的训练 | 同步，再删除该训练；切到无记录范围 | 按训练键只计一次，删除后对应桶减少，空范围展示空状态 |
