# 06 围度

## 需求

用户在「统计 → 围度」可按日记录内置身体部位，按日期更正或清除，选择一个部位查看历史。一天可先填部分部位，之后接着补。

## 实现设计

- 复用上游 [`MEASUREMENT_FIELDS`、`normalizeMeasurementsState`、`measurementSeries`](../../../frontend/src/lib/measurements.js) 的字段和读写规则。记录沿用 `Profile.measurements[]`，每个本地日期最多一项。长度统一保存为 cm，显示和输入按工作区用 cm 或 in，输入使用 `fromMeasurementDisplay`。
- 操作携带日期与明确的设值/清除字段，应用到最新同日记录后保留其余数据。整日删除使用上游 `deleted.measurements` 约定。Web 的 `other`、体脂和自定义字段可随资料读回并保存，RN 的围度编辑面板操作内置长度字段。
- 复用 `Screen`、`TextField`、`ListRow` 记录和回看。单一部位曲线按日期排序，缺失的值跳过。显示当前单位及允许录入的日期，区分空字段与已有记录。

## 执行步骤

1. 接入日期合并、单位转换和字段级更新。完成独立围度页面后接历史及单部位趋势。
2. 用同日多部位、跨日曲线与 Web 同步 fixture 执行下表，记录 UI 显示和 API 的日期、值、删除标记。

## 验收目标

| 编号 | 前置条件 | 操作 | 通过标准 |
| --- | --- | --- | --- |
| 1 | 账号当天无围度 | 先保存胸围 96 cm，再补腰围 80 cm | 历史只有一个日期项，API 同日包含 `chest:96` 与 `waist:80` |
| 2 | 磅单位账号以英寸录入；已有另一天的同部位值 | 填前臂 10.0 in，查看 API，再用公制数据查看 | 存为 25.4 cm；英制显示 10.0 in；曲线顺序及日期准确 |
| 3 | 有两天腰围，另一天只填了胸围 | 查腰围趋势，清除其中一天的腰围 | 缺腰围的日期无数据点；清除后删除对应点，胸围数据可读回 |
| 4 | 有 Web 添加的同日自定义指标；RN 离线改腰围，Web 同时改胸围 | 重连后同步，再通过 Web 读回 | 两部位分别保留各自改动，自定义指标仍在，只有一个日期项 |
| 5 | 空白或已有某日记录 | 尝试保存非法日期、非正长度或全空新记录；然后删除已有整日 | 无效输入有反馈；整日确认删除后重同步不恢复该日 |
