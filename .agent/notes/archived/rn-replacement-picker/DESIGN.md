# RN 训练替换动作选择器设计

基线 `42411be33`。目标是让用户能先看动作演示，再明确确认替换，同时保留列表快捷选择。

## 范围与现状

本次将截图中的「选择备选动作」落在 RN 训练页「搜索替换动作」入口。[WorkoutScreen](../../mobile-rn/src/screens/WorkoutScreen.tsx) 传入动作索引，[App](../../mobile-rn/App.tsx) 打开 `panel.kind === 'library'`，并通过 `pickForWorkout(target, replaceIndex)` 替换当前训练中的动作。计划自带备选项的直接切换、训练中新增动作、计划编辑器和独立动作库沿用各自的选择交互。右上角漏斗属于共享动作库的筛选入口，因此各调用方统一换图标。

[ExerciseLibraryScreen](../../mobile-rn/src/screens/ExerciseLibraryScreen.tsx) 当前点行即选择，信息按钮打开详情，内置动作有加号，自定义动作有编辑按钮。详情分支会卸载列表。[ExerciseDetailScreen](../../mobile-rn/src/screens/ExerciseDetailScreen.tsx) 已有底部选择按钮，可复用。[ListRow](../../mobile-rn/src/design/components/ListRow.tsx) 将 trailing 渲染在外层 Pressable 内，本次替换模式需要独立点击区。

## 交互契约

- **R1 查看详情。** 缩略图、标题、副标题及左侧空白构成一个点击区。打开同一动作的现有详情。详情页头返回和 Android 返回键都回到选择器，保留搜索、筛选及列表滚动位置。关闭选择器才回训练。
- **R2 收藏与快捷选择。** 每行右侧只放星标和加号，内置和自定义动作一致。星标复用现有收藏写入和「仅收藏」行为，加号立即提交。三个点击区为同级可操作控件，分别朗读「查看详情」「收藏／取消收藏」「选择替换动作」及动作名，点击互不触发。「创建自定义动作」仍可用，自定义动作编辑可从普通动作库进入。
- **R3 从详情确认。** 复用详情末尾主按钮，文案定为「选择此动作替换」，明确替换当前训练中的动作。加号和详情按钮提交同一个动作 ID 与模式，通过列表已有的内置或自定义选择逻辑推导 `reps` / `cardio`，再走原有替换回调。两条路径成功后均关闭选择器，回到训练并显示所选动作。同一打开周期内只接收一次确认。未确认返回时训练草稿不发生替换。详情继续使用已有媒体及缺失时的展示。
- **R4 筛选图标。** 右上角圆形按钮改用设计系统漏斗图标，继续打开原面板，沿用当前计数、强调色和无障碍文案。其他滑杆图标继续用于原入口。

## 实现边界

App 根据 `replaceIndex != null` 显式传入替换模式，包含索引 0。模式只影响选择器行和详情确认。保留现有 `RoutineExercise` 回调与训练状态更新，同模式下已有组数、次数、休息等参数沿用当前 `pickForWorkout` 规则。选择器由 App 外层 Modal 承载。替换模式可用详情覆盖层保留已挂载列表，覆盖层显示时隐藏底层列表的触摸和无障碍焦点，并用覆盖层的 `onRequestClose` 优先关闭详情。返回时恢复同一个列表实例，避免按索引重建滚动位置。
