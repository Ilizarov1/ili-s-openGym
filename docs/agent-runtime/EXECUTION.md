# openGym Agent 运行环境执行计划

[需求](REQUIREMENTS.md) · [技术设计](DESIGN.md)

状态为待执行。所有命令使用 PowerShell。以下检查在实施对应阶段时运行。

## 阶段 0 建立基线

- [ ] 记录工作树状态、Node、npm、Java 和 Android SDK 版本，保留已有改动。按现有指引选择独立的 API 数据目录及 RN 设备。详见 [NestJS 实施与验收](../../archive/nestjs-migration/EXECUTION.md) 和 [RN Android 实施与验收](../../archive/RN_ANDROID_EXECUTION.md)。
- [ ] 确认 RN 工作区切换、SQLite 初始化和 SecureStore 命名入口，确认 NestJS 模块注册、鉴权、请求体读取和服务退出流程。
- [ ] 检查 Coach 适配器的依赖树与错误输出。记录哪些模块可供 Metro 和 Node 直接使用，哪些继续由现有 Coach 使用。
- [ ] 固定一份桩数据，包含两个账号、两个工作区、同一对象的两个版本、未同步记录和小型图像。桩模型提供正常结果、工具请求、超限、错误与被取消后晚到的成功响应。使用虚构凭据，外部网络调用计数应为零。

阶段产出为源码基线、复用清单及桩输入。已有行为回归在实施前按相关范围记录。

## 阶段 1 共享契约与执行核心

- [ ] 新增 `api/agent-runtime/`，落地任务注册、运行上下文、模型输入和输出校验。先实现固定流程与一个受限工具调用步骤，均通过注入适配器运行。
- [ ] 实现工具派发和稳定错误码。用桩工具计数验证拒绝发生在调用前。实现证据映射、可选上下文裁剪及必要事实缺失错误。
- [ ] 实现运行状态转换、超时和取消。结果提交由宿主做条件写入，桩用例覆盖取消与完成竞争。实现提案确认的契约，用原子写入桩验证并发确认和版本冲突。
- [ ] 在 `api/test/agent-runtime.test.js` 放置共享契约用例。更新 Metro 和 API 构建，验证 API 镜像从自己的构建上下文包含共享核心。

退出条件为验收 A2、A3、A4、A7 的共享契约用例通过。RN 和 API 都能加载同一份共享源码。

## 阶段 2 接入本机执行

- [ ] 在 `mobile-rn/src/agent/` 实现本机执行入口及作用域绑定。通过当前工作区读取数据，使用 SQLite 保存 Agent 记录。对工作区切换前已开始的作业保持原作用域。
- [ ] 在 SecureStore 保存模型凭据，SQLite 保存配置元数据，封装 HTTPS 请求与取消。配置写入失败时清理孤立凭据或恢复旧配置。
- [ ] 接入会话与长期记忆仓储，验证删除和运行完成交错时的处理。应用重启后识别遗留的非终态运行。
- [ ] 在开发入口或验收夹具上跑本机执行，验证无配对运行、未同步数据读取、切换工作区与凭据保管。若新增开发界面，先按 [RN 设计系统](../RN_UI_DESIGN_SYSTEM.md)、[页面迁移](../RN_UI_SCREEN_MIGRATION.md) 和 [视觉验收规范](../RN_UI_VISUAL_TESTING.md) 执行。

退出条件为 A1 的本机路径、A2、A5、A7 在 RN 验收环境复现。

## 阶段 3 接入服务端执行

- [ ] 在 `api/src/agent/` 注册 NestJS 模块和鉴权路由，更新 `api/openapi.yaml`。实现账号作用域内的配置、会话、记忆和作业存储。
- [ ] 适配管理员默认模型及账号级用户配置。验证加密写入、重启解密、配置撤销、跨账号隔离与日志脱敏。记录加密密钥的部署配置与恢复条件。
- [ ] 实现作业创建、状态查询、取消和启动恢复。按账号串行处理状态写入和请求去重，覆盖并发提交与带差异输入的请求 ID 重用。
- [ ] 用独立数据目录及桩模型运行 API 集成验收。复查现有 Coach 路由行为，验证旧账号在首次使用 Agent 时可按需初始化。

退出条件为 A1 的两条服务端路径、A5、A6、A7 在 API 验收环境复现。

## 阶段 4 双端集成验收与交接

- [ ] 从 RN 验收入口分别选择本机、服务端默认和服务端用户配置。用同一份桩快照对照结果结构和证据，切到包含未同步记录的工作区复查两端数据边界。
- [ ] 按下表逐条保留命令、版本、前置数据、实际结果和通过状态。真实提供商联调如执行，记录能力和错误类别，避免保留密钥和请求正文。
- [ ] 记录实施后的目录职责、API 配置和首版限制。更新 RN 迁移清单及文档入口。对未执行的环境检查标注待验。

## 验收对照

| 编号 | 需求 | 操作与可观察结果 |
|---|---|---|
| A1 | R1 | 分别用三种配置运行桩任务。远程适配器收到所选模型配置，运行记录只含引用。当前配置被撤销或缺少图像能力时返回明确错误，无自动转发。 |
| A2 | R2 | 注入他人引用和超预算上下文。越权引用被拒绝，可选内容被裁剪，必要事实保留，引用仍能回查版本。本机额外读取未同步记录。 |
| A3 | R3、R4 | 让模型返回未知工具、参数错误、真实但越界的 ID、当前步骤禁用工具。所有拒绝用例的底层执行次数均为零。有效请求在预算内执行并返回。 |
| A4 | R4 | 生成提案后分别省略确认、并发确认、先修改目标再确认。写入次数分别为零、一次、零。冲突返回可识别状态。 |
| A5 | R5 | 保存偏好后切换账号或工作区，删除偏好后再次发起，运行中删除会话。跨范围和已删记录均不进入新上下文，已删会话不会被晚到结果重建。 |
| A6 | R6 | 并发重试同一服务端请求并模拟响应丢失，按 ID 重连查询。同一请求返回一个作业和一次模型调用，复用请求 ID 但改输入则冲突。 |
| A7 | R6 | 取消后送达模型响应，另在运行中终止并重新启动宿主。晚到结果没有提案，取消状态仍可查询，重启后的遗留作业标为中断，已有结果可读。 |

## 启用与回退

先在本地和独立实例启用验证入口。启用时保留独立的 Agent 记录和配置，新增存储按需初始化。需要回退时先停用 Agent 入口，再按现有部署流程回退应用版本。保留已有业务数据与 Agent 记录，恢复启用时验证存储可读和密钥可用。
