# 05 体重

## 需求

用户在「统计 → 体重」按本地日期与时间新增、更正或删除称重，可看到当天读数、日值和周趋势。同日可以有多次读数，本机练习和每个配对账号各自保存。

## 实现设计

- 使用上游 [weigh-ins.js](../../../frontend/src/lib/weigh-ins.js) 的 `readingsOf`、`addWeighIn`、`editWeighIn`、`removeWeighIn`。沿用 `Profile.bodyweight[]` 的 `d/w/t/ins/gone`，兼容只有 `d/w/t` 的旧读数。同日同分钟手动填写视为更正，日期和时间使用设备本地日历。
- 日值按 `bwDaily` 的首笔、均值或末笔处理，缺省首笔。周趋势复用 [`weeklyWeights`、`weighInAt`](../../../frontend/src/lib/bodyweight.js) 和周起始设置。体重以记录所属账号单位保存，待同步操作带输入单位和稳定读数 ID，重放时按目标单位换算一次。
- `StatsScreen` 接入新页面，日期与读数编辑复用设计组件。体重按日期、读数 ID 写操作；同日其他读数沿用服务器版本。删除一笔更新 `gone`，删除最后一笔用上游日记录删除语义。

## 执行步骤

1. 接入旧读数解析、录入、更正、删除及按读数重放，再做周趋势和详情表单。
2. 用可见模拟器录入固定日期样本，核对单位与周均。用独立 API 对照 `ins/gone` 并验证下面的并行修改。

## 验收目标

| 编号 | 前置条件 | 操作 | 通过标准 |
| --- | --- | --- | --- |
| 1 | 空白 kg 工作区 | 同日 08:00 记 70.2、20:00 记 71.0；把 08:00 改为 70.5 | 同日两笔，08:00 更正为 70.5 且保留 20:00 的 71.0，日期、单位准确 |
| 2 | 一周里第一天读数 70/74 kg，第二天有 72 kg | 分别以首笔和均值模式查看周趋势 | 日值分别为 70/72 与 72/72，周均分别为 71 与 72 kg，周均基于日值 |
| 3 | 有一条仅含 `d/w/t` 的旧记录，另有 70.0 kg 可换算 | 读取旧记录，切换到等价的 lb 同步数据 | 旧记录可显示和更正；同一称重读数在 lb 下约为 154.3 lb，时间不变 |
| 4 | 编辑表单为空或非法日期、0、负数、非数值 | 尝试保存并返回列表 | 指出无效字段，API 和本机列表无新增读数 |
| 5 | 配对账号离线删除早晨读数，同时 Web 在同日新增晚间读数 | 重连同步两次，再删除该日最后一笔 | 早晨读数仍已删除，晚间读数保留一次；最后一笔删除后日值和周趋势不再包含该日 |
