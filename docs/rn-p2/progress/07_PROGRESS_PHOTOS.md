# 07 进度照片

## 需求

用户在「统计 → 进度照片」从系统照片选择器选一张图片，确认本地日期后保存，可按日期浏览、全屏查看和删除。在本机练习可离线使用；已配对时同步到支持该类照片的实例。

## 实现设计

- 使用 Expo 系统照片选择器和图像重编码，按实例 `/api/config` 的图片大小限制生成文件，校验方向、大小和 SHA-256，并生成上游 `MediaRef`。待同步源文件保存在应用私有目录，日常浏览复用 `expo-image` 及 [动作演示已有媒体读取](../../../mobile-rn/src/exerciseMedia.ts) 的认证与哈希校验思路。[Expo ImagePicker](https://docs.expo.dev/versions/v55.0.0/sdk/imagepicker/) · [Expo ImageManipulator](https://docs.expo.dev/versions/v55.0.0/sdk/imagemanipulator/)
- 复用 [`fileProgressPhoto`](../../../frontend/src/lib/day-photos.js) 与 [workout-media.js](../../../frontend/src/lib/workout-media.js)。当天最新训练可附图且有空位时存入 `workout.media`（最多 6 个媒体），其余走 `Profile.dayPhotos[hash]`，取决于 `media.days`。当前实例能力不足时在确认前显示提示。
- 已配对时先上传文件到 `PUT /api/media/{hash}`，文件确认后再同步引用，失败时待同步可重试。按账户和实例隔离文件。删除按上游标记更新日期或训练引用，服务器通过既有回收规则处理文件。[API 契约](../../../api/openapi.yaml)

## 执行步骤

1. 接入照片选取、方向及体积检查、日期确认、私有本机存储和图库；先验证练习模式。
2. 接入已配对队列、能力检测、上传和引用删除。用开启媒体的独立 API、Android 模拟器和真机按验收表检查。准备合成测试图片用于日志、截图和文件校验。

## 验收目标

| 编号 | 前置条件 | 操作 | 通过标准 |
| --- | --- | --- | --- |
| 1 | 本机练习、断网，一张横向存储但带旋转信息的测试照片 | 选图并保存到过去某日，重开后查看全屏 | 只有一张日期正确、方向正确的图片，重开可查看 |
| 2 | 媒体已启用；日期 A 有两场训练且最新一场还有空位，日期 B 无训练 | 在 A、B 各添加一张可区分的图片 | API 中 A 的新引用在最新那场 `media`，B 在 `dayPhotos`；Web 同账号可浏览两张 |
| 3 | 实例可附训练媒体，`media.days` 缺失，所选日无训练或已满 | 选择图片并确认日期 | 提示实例不支持该日照片，已保存照片与训练列表保持原样 |
| 4 | 已配对且缓存了支持能力，断网选图 | 保存，重开，恢复网络并在引用提交时模拟一次重试 | 离线显示待同步；上传确认后 API 出现一份可读取的引用；重试后仍为一张 |
| 5 | 账号 A 已保存图片；账号 B 未添加 | 删除 A 图片，同步后切换 B，再回 A | B 看不到 A 的图片；A 删除状态重同步后仍生效；训练其他字段和媒体引用可读回 |
| 6 | 选图取消、文件不可解码或重编码后仍超实例限制 | 分别尝试保存 | 取消直接回列表；异常提示对应原因；API 无新增图片引用 |
