# RN 训练动作卡片与递减组设计

设计版本 v1，基于仓库 `42411be33`。状态为已实施并通过 Android 模拟器验收；验收证据见 [验收记录](ACCEPTANCE.md)，实施与用例见 [执行文档](EXECUTION.md)。

## 1. 需求和范围

| 编号 | 需求 | 成功条件 |
|---|---|---|
| R1 | 组行拥挤，重量、次数步进按钮和勾选重叠 | 点重量或次数直接输入。组号、重量、次数、评分、完成状态和行尾菜单对齐且可独立点按 |
| R2 | 动作操作与组操作分开 | 搜索替换只在动作菜单。组尾菜单可转换组类型、复制、删除以及进入分段编辑 |
| R3 | 热身组有明确入口和状态 | 普通组可转热身，热身可转正式。分别编号，重量、次数和完成状态保留 |
| R4 | 递减组易于创建、增段、查看和还原 | 通过底部面板配置，保存后自动展开。训练中可在展开区快速加段。可直接改回普通组 |
| R5 | 逐段打勾，整组完成后才进入休息 | 最后一段前没有整组完成事件。最后一段原子提交整组完成并走现有休息、超级组及完成提示规则。重开能继续 |
| R6 | 暂时移出休息暂停组的日常入口 | 当前训练不再提供新建或转换入口。已配置的计划、草稿和历史继续读写，已有训练仍能完成 |

卡片、列表和紧凑布局共用组行。专注布局只接通递减组完成规则和旧休息暂停组兼容路径，沿用其单组界面。计划编辑、历史编辑、Web 和 API 的界面、历史契约和同步协议不在本轮变更范围。

## 2. 已核实的实现基线

- [WorkoutScreen](../../mobile-rn/src/screens/WorkoutScreen.tsx#L436) 共用 `renderExerciseCard`。重量和次数所在的弹性列各含固定尺寸的 [Stepper](../../mobile-rn/src/design/components/Stepper.tsx#L110)。评分和组类型按钮各占额外的行。`exerciseMenuItems` 已有搜索替换，卡片底部还有重复入口。组号为静态文字。
- [WorkoutSetField](../../mobile-rn/src/screens/WorkoutSetField.tsx#L26) 在聚焦时保留半输入文本，有效值才写草稿，失焦回退无效文本。[WorkoutFocusView](../../mobile-rn/src/screens/WorkoutFocusView.tsx#L73) 有自己的组行与完成按钮，最终调用 `WorkoutScreen.toggleSet`。
- [训练模型](../../mobile-rn/src/training.ts#L230) 中 `DraftSet.at` 表示整组完成，`drops` 和 `clusters` 保存分段参数。分段暂无完成状态。[toggleSet](../../mobile-rn/src/screens/WorkoutScreen.tsx#L310) 统一处理整组完成、撤销、位置和休息。[supersets.ts](../../mobile-rn/src/supersets.ts#L17) 按整组完成状态推进轮次。
- 草稿经 [App.openWorkout](../../mobile-rn/App.tsx#L222) 写入 [useGym](../../mobile-rn/src/useGym.ts#L40) 管理的本地状态，[storage.ts](../../mobile-rn/src/storage.ts#L53) 读回 JSON。 [finishWorkout](../../mobile-rn/src/training.ts#L1108) 显式投影历史行，递减组保存为一条记录，统一用 `type/drops` 表达。未完成行沿用现有部分完成保存规则。

## 3. 卡片和菜单

```text
杠铃全蹲                                             ⋯

组          重量·kg     次数     RPE     完成
热身1          20         10       —       ✓      ⋯
热身2          40          8       —       □      ⋯
1              60          8       8       ✓      ⋯
2 ▸            60          7       —      1/3     ⋯
  递减组 · 50 kg × 8 → 40 kg × 9
3              60          8       —       □      ⋯

[＋ 添加正式组]
```

- 主行复用现有字段校验、单位、重量联动和已完成组纠错。输入重量使用小数键盘，次数使用整数键盘。有氧和计时组保留速度、分钟、秒等原有字段和键盘。各交互列至少保留 44×44 dp 的独立触控区，递减组点组号处的箭头展开，展开入口暴露当前展开状态。320 dp 宽的窗口采用窄屏留白，不能直接沿用默认页面及卡片各 16 dp 的左右内边距。以六列各 44 dp、五个 2 dp 列间距计算，页面和卡片合计左右留白最多 46 dp。长标签、放大字体和分段摘要可以换行。
- 普通组和热身组在主行打勾。递减组的完成列显示已勾段数/总段数，完成后显示 `✓`。该列点按只展开或收起分段。收起摘要包含每段重量和次数。超过一行按顺序换行。
- 评分入口直接显示数值或 `—`，点击打开现有评分面板，支持填写、修改和清除。热身行保留空位并禁用评分。整张卡仅有一种尺度时在表头显示 RPE 或 RIR。混合尺度时表头显示「评分」，每行带自己的尺度。关闭评分且没有已存评分时可省略整列。
- **RPE 是主观用力程度。递减组整组只评一次。** 评分显示在主行，覆盖主段和所有降重段。分段行只显示重量、次数和勾选。用户可以在最后一段做完后点主行补填，评分可选，完成时不自动弹出面板，也不阻塞开始休息。草稿中的评分可修改或清除，保存训练时只有已完成的正式组会写入历史评分。
- 动作菜单保留现有「搜索替换动作」与可用的超级组操作，移除底部重复的搜索按钮。已有一组完成时维持替换限制。递减组已有任意段完成时也禁用替换，避免把已经记录的训练换成另一个动作。

```text
普通组                   热身组                   递减组
第 1 组                  热身第 1 组              第 2 组 · 递减组
────────────────         ────────────────         ────────────────
设为热身组               改为正式组               编辑分段 ›
改为递减组 ›             复制这一组               改为普通组
复制这一组               删除这一组               复制这一组
删除这一组                                        删除这一组
```

- 力量普通组可转热身。热身移到热身区末尾，改回正式组时放到首个正式组位置。保留当前重量、次数和完成时间，热身不保留评分。手工转换行应保留手填重量，后续自动热身联动不会覆盖。保持其他行的身份，重映射休息条所属组。递减组可先回到普通组，再转为热身。
- 复制紧跟原组，携带重量、次数、组类型和分段参数，分配新组与新分段标识。新行无评分、无整组完成时间、无分段勾选。正式组上限沿用 `MAX_WORK_SETS`。
- 删除只对未完成行开放。已有分段勾选的递减组删除前提示将丢弃分段进度。隐藏完成组删除入口。仅力量且未完成的普通组显示「改为递减组」。
- 已有休息暂停组的兼容路径，从组行的「休息暂停组」摘要按需打开现有分段内容，沿用整组勾选和原有历史投影。卡片不铺开短休分段，组尾菜单没有转换入口。无需为这些组补做逐段状态或计时。

## 4. 递减组的创建、编辑、快速记录

点组尾菜单「改为递减组」后，同一底部弹层切换为编辑表单，背景仍是训练卡片。主段沿用现有重量和次数，首个降重段由既有降重比例及档位规则预填，次数沿用主段。图中的数值为示例。

```text
│ 杠铃全蹲                              ⋯ │
│ 第 2 组      60 kg     7 次    □     ⋯ │  背景变暗
╭─────────────────────────────────────────╮
│ 第 2 组 · 改为递减组                    │
│ 主段         60 kg × 7 次               │
│ 降重 1      [50 kg] × [7 次]     删除   │
│                                         │
│ ＋ 添加降重段                           │
│ [取消]                           [保存] │
╰─────────────────────────────────────────╯
```

转换和编辑均在面板内暂存。取消、返回和点击背景关闭均丢弃未保存修改。保存验证主段与分段，错误显示在对应字段，保留面板及输入。新建递减组至少需一个降重段。成功提交后关闭面板并展开该组，进度 `0/2`，无自动计时。

```text
2 ▾         60 kg      7 次     RPE —     1/3     ⋯
            主段       60 kg × 7 次       ✓
            降重 1     50 kg × 8 次       □
            降重 2     40 kg × 9 次       □
            [＋ 添加降重段]
```

展开区的「添加降重段」直接更新草稿，不经过面板。重量根据上一段按现有规则预填，次数沿用上一段。新段待完成，原有勾选保留，进度的分母增加。降重段数字可直接点击输入。主段参数在卡片主行修改。比如 `1/3` 时追加一段变为 `1/4`。

```text
╭─────────────────────────────────────────╮
│ 第 2 组 · 编辑递减段                    │
│ 主段         60 kg × 7 次               │
│ 降重 1      [50 kg] × [8 次]     删除   │
│ 降重 2      [40 kg] × [9 次]     删除   │
│ ＋ 添加降重段                           │
│ [取消]                           [保存] │
╰─────────────────────────────────────────╯
```

- 编辑分段按标识保留现有勾选。删除已勾段需确认。保存会验证现在的进度和列表，删除未勾段导致剩余段都已勾时，保留至少一个待完成段。面板提示先取消最后一段完成或保留待完成段，避免删除触发组间计时。
- 「改为普通组」和编辑页删光降重段共用还原规则。保留主段重量、次数与整组评分，移除降重段和分段进度。已有降重段勾选时先确认。主段已完成则恢复为完成的普通组，沿用主段完成时间。此操作不启动或重置休息。主段未完成时显示普通组的空勾选。
- **完成后的处理已按本设计确认。** 整组完成后可改重量、次数和评分，追加、删除及改组类型锁定。若要变更结构，可展开取消最后一段的勾选，回到进行中。撤销仅清除该组所属的休息，保留其他组的休息。已完成组可复制，复制无需撤销。

## 5. 草稿、分段完成和兼容契约

| 状态或操作 | 草稿约束与可观察结果 |
|---|---|
| 保存新递减组 | `DraftSet.at = null`。主段和各降重段完成时间为空，主行显示 `0/N` |
| 完成一段 | 在草稿层为主段和每个降重段记录可选完成时间。建议分别扩展 `DraftSet.mainAt`、`DraftDrop.at`。完成按显示顺序，只允许勾下一段，撤销只针对最后一个已勾段。当组合法且可按超级组顺序执行时才允许勾选 |
| 完成最后一段 | 分段变化、`DraftSet.at`、休息及位置以一次草稿提交保存。共用整组完成入口。点按命令携带分段标识、预期旧状态和目标状态。应用到最新草稿，重复的同一完成命令直接返回，已完成的段不会因重试再次提交或重置计时 |
| 中途保存整场训练 | 沿用现有部分完成语义。存在部分已勾的递减组时，结束确认明确说明这组未完成，分段勾选只在草稿保留。用户可取消结束并继续。确认保存时按现有规则保存未完成组或剔除无已完成组的动作 |
| 取消最后一段完成 | `DraftSet.at` 回到空，其他段保留已勾。按现有整组撤销口径，仅清除属于本组的休息，不重新弹完成提示 |
| 读回旧草稿 | 没有分段进度字段时，旧递减组 `DraftSet.at` 有值即所有段已完成，否则所有段未完成。首次改动旧已完成组时先用已有整组完成时间初始化缺少的分段时间，再应用撤销等变更。受影响的旧无标识行在首次编辑时分配并保存稳定标识。新草稿读回以实际分段进度为准 |
| 保存本场与同步 | 继续用 `finishWorkout` 投影一条整组记录，保留现有 `type/drops`、评分及训练量口径。草稿专用键及分段完成字段不写入历史或同步载荷 |
| 提交失败 | 保持原草稿、计时及面板状态，可重试。UI 的关闭、自动滚动、完成提示和下一个焦点均在持久化成功后执行 |

作用于组或分段的菜单、编辑面板和动作回调以稳定标识查找当前草稿，目标已被删除或不再匹配时取消提交。复制、删除、热身转换导致行位置变化时，把既有休息引用重映射到原组；删除休息所属组时遵守现有清理规则。放弃分段、取消勾选和重复点按不得影响其他组的完成状态。

实施沿用 [设计系统](../RN_UI_DESIGN_SYSTEM.md)、[页面规范](../RN_UI_SCREEN_MIGRATION.md) 和 [视觉验收](../RN_UI_VISUAL_TESTING.md)。采用表格式主行和分段展开，展开时可以查看各段参数并直接勾选。底部面板用于批量配置，转换过程可取消。
