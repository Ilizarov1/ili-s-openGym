# openGym RN 客户端迁移清单

基线为 Android `0.1.0`。已跑通「选计划 → 记录重量和次数 → 查看历史 → 同步到现有服务器」。以下按仓库中的[上游功能](../README.md#features)和[原移动端说明](MOBILE.md)盘点。

## 已完成

- [x] Android 独立安装包。使用 Expo + RN，可侧载并与官方客户端共存。
- [x] 本机练习。内置两套示例计划，可离线训练。
- [x] 查看和执行训练计划。支持服务器计划、上游动作 ID、中文动作名和自定义动作名称。
- [x] 基础力量训练。输入重量和次数，勾选或取消完成，结束或放弃训练。SQLite 保存进行中的草稿，重开可恢复。
- [x] 查看训练历史。可展开查看动作和组数据，待上传记录有状态提示。
- [x] 手动配对。输入服务器地址和一次性配对码，支持断开和重新配对，令牌存入 SecureStore。
- [x] 同步已完成训练。从服务器拉取计划和历史，上传 RN 新增训练。支持前台定期同步、手动同步、离线补传、`409` 重试和按训练 ID 去重。
- [x] **组间休息倒计时**。自动开始，支持按动作或账号设置时长、取消、回前台和重开恢复。Android `0.1.1` 模拟器验收通过。[验收记录](RN_ANDROID_EXECUTION.md#011-验收结果)
- [x] **沿用上次训练重量**。预填最近一次可比较的正式组重量，用户可以修改。Android `0.1.1` 模拟器已验证下一次训练预填，另通过单位换算和计划值回退检查。[验收记录](RN_ANDROID_EXECUTION.md#011-验收结果)
- [x] **训练中增删组**。可追加正式组或删除未完成的组，保留已完成记录和正在运行的休息计时。
- [x] **记录计划里的热身组**。历史和同步保留热身标记。热身组不参与上次正式组重量预填，训练量按账号设置计算。
- [x] **使用计划里的备选动作**。记组前可切换或换回，保留计划组数、次数、休息和热身配置，按实际动作保存历史。

首版已在 Android 36 模拟器验证断网训练、重启恢复和联网补传，并用独立 API 实例验证冲突重试与去重。[首版验收记录](RN_ANDROID_EXECUTION.md)

## 迁移进度与优先级

按「继续在网页端管理计划，主要用 RN Android 在健身房记录力量训练」排序。P0 补齐训练现场的高频操作，P1 让客户端能独立管理训练和数据，P2 补充进阶体验与平台能力。

P0 功能已在 Android `0.1.2` 可见模拟器上验收，设备验收见下方清单。[P0 验收记录](RN_ANDROID_EXECUTION.md#p0-收尾)

### P1 · 补齐手机端管理

- [x] **历史纠错与同步**。可编辑日期、名称和组记录，补录过去的训练。模拟器和独立 API 已通过离线修改、保留网页端变更、删除及指定日期补录。
- [x] **计划管理与同步**。模拟器和独立 API 已验证创建、编辑、删除、每周排程、按顺序轮换以及今日推荐。删除计划后同步清除排程引用。
- [x] **动作库与自由训练**。模拟器和独立 API 已验证目录搜索、自定义动作创建和改名、自由训练加动作，以及未记组时搜索替换。
- [x] **按动作查看历史**。可见 Android 模拟器已从训练详情打开单动作历史并返回。
- [x] **组间到点通知**。已在 Android 36 模拟器授予通知和精确闹钟权限，熄屏后系统在休息结束时发布通知。真机锁屏显示及震动见工程验收。
- [x] **备份与恢复**。模拟器已验证本机练习合并到账号、Android 文件选择、重复导入去重、磅到公斤换算和打开 JSON 导出的系统分享面板。
- [x] **有氧与计时动作**。模拟器已完成混合训练，历史与独立 API 确认保存了计时组的时长和负重、有氧组的时长和速度。

### P2 · 进阶体验与平台扩展

逐项需求、设计、执行步骤和验收目标见 [P2 功能文档](rn-p2/README.md)。

#### 高级训练

- [x] **超级组**。Android `0.1.4` 已验证计划和训练中组合与拆分、不同组数的轮转、轮末休息、重开恢复、历史展示和同步。[验收记录](RN_ANDROID_EXECUTION.md#014-验收结果) · [新版验收目标](rn-p2-training-library/01_SUPERSETS.md#验收目标)
- [ ] **递减组**。已实现，待按分段、训练量和同步目标验证。2026-11-17 模拟器已用 `fixture-advanced` 验证计划生成、训练页可编辑降重段、历史 `100×5 → 80×5 → 64×5` 摘要和 RPE 共存；API 同步、1220 训练量和单位换算待复验。[验收目标](rn-p2-training-library/02_DROP_SETS.md#验收目标)
- [ ] **休息暂停组**。已实现，待按短休、总次数和训练量目标验证。2026-11-17 模拟器已验证 `12` 次生成 `6 + 3 + 2 + 1`、每段 15 秒和整组显示；完成落盘、720 训练量及同步待复验。[验收目标](rn-p2-training-library/03_REST_PAUSE.md#验收目标)
- [ ] **RPE**。已实现，待验证评分录入、更正和清除。2026-11-17 模拟器已验证训练页 RPE 8 保存、历史显示 `RPE 8`；低于 6、清除、断网重开和 API 读回待复验。[验收目标](rn-p2-training-library/04_RPE.md#验收目标)
- [ ] **RIR**。已实现，待验证零值、尺度切换和旧数据。2026-11-17 模拟器已验证设置切到 RIR 后训练页显示 RIR 评分入口；0、0.5、换算和旧双字段待复验。[验收目标](rn-p2-training-library/05_RIR.md#验收目标)
