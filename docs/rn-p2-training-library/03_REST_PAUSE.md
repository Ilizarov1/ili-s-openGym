# 03 休息暂停组

## 需求

用户可在力量计划设置目标总次数及分段间短休，也可在训练中将原组作为第一段，追加短休后的次数。用户按记录的秒数自行休息，训练界面显示并允许调整分段。

1. **计划执行**。设总次数 12、短休 15 秒。开训生成一组热身和一组休息暂停正式组，正式组显示 `6 + 3 + 2 + 1`。原组数设置不重复生成整套分段。
2. **手动调整**。追加、修改、删除分段时，总次数随分段更新。已有正式组手动转换时，原次数作为第一段计入总次数。删除附加分段后可恢复普通组。可在设置调整手动加段的默认短休。
3. **结果**。用 60 kg 完成总计 12 次，默认排除热身时训练量为 720。历史、离线草稿和 API 读回分段次数及休息秒数，整组计为一组。

## 实现设计

- 计划使用 `intensifier: { type: 'restpause', totalReps, restSec }`，正式组使用 `type: 'restpause'` 与 `clusters: [{ r, restSec }]`，`r` 始终等于各段次数之和。按当前 [生成规则](../../frontend/src/lib/history.js)，计划的普通次数字段用于热身，首个 cluster 是正式组的第一段。
- 复用递减组接入的高级组字段、编辑结构和训练量计算，在 [training.ts](../../mobile-rn/src/training.ts) 用上游 `applyIntensifierPlan`、`splitBurstReps`、`nextBurstReps` 生成，用组级更新操作保持总次数一致。计划配置的短休优先，手动加段继承已配对 Web 的 `restPauseSec`，缺省 15 秒。新增设置沿用上游 5–300 秒区间。
- `Stepper` 编辑分段次数和短休秒数，分段区域显示整组总次数。整组完成后走现有组间计时，短休分段本身只显示秒数。RN 新记录沿用双侧合计输入，历史中已有逐侧分段结构保留。

## 执行步骤

1. 接入计划参数、默认短休设置、正式组分段生成和手动加段，使用同一组级更新入口处理训练及历史纠错。验证计划切为普通组、编辑或删除末段、继续旧草稿时的数据表现。
2. 用计划和自由训练各执行一次，验证 12 次、720 训练量、15 秒短休元数据与历史显示；核对计划明确设置时覆盖账号默认值。复验离线重开，同步后核对 `r === sum(clusters[].r)`，并检查超级组只在整组完成时推进。
3. 执行 [共用验收](README.md#共用验收)，记录分段回读、无重复计量和现有组间计时的结果。
