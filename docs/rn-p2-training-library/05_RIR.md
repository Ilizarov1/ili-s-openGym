# 05 RIR

## 需求

用户可在力量正式组记录还能完成的次数，在历史更正或清除。RIR 与 RPE 是同一组的两种评分尺度。

1. **尺度与零值**。设置「训练评分 → RIR」后，可保存 RIR 0、0.5、2 和 10。RIR 0 表示没有余量，清除后显示未评分。有氧仍用 RPE。
2. **切换尺度**。已有 RPE 8 可读作 RIR 2。切换设置本身保留历史原始字段，只有用户保存本组的新评分才替换旧尺度。
3. **兼容**。旧 `showRir: true` 可识别，显式「关闭」优先。若旧组同时有两种值，读取优先 RIR；只有力竭标记且无显式评分时，按上游规则可推得 RIR 0。

## 实现设计

- 在 [RPE 共享选择器](04_RPE.md) 和 `profile.effort` 设置中加 RIR 选项。复用 [`rirOf`、`toScale`](../../frontend/src/lib/effort.js) 和 [`EFFORT`、`effortOf`](../../frontend/src/lib/history.js)，步进 0.5，精确输入 0–10。
- 历史回读优先显示本组实际保存的尺度。打开编辑器时可换算成当前尺度，用户确认才写 `set.rir` 并移除 `set.rpe`。力竭推导值与主动写入的评分在界面上可区分。切换偏好不重算历史数据。
- 草稿、历史更正与同步共享 RPE 的保存路径。有 `sides` 的旧记录保留逐侧字段，避免把单个合计评分写回两侧。

## 执行步骤

1. 在现有设置、训练组菜单和历史选择器加入 RIR，覆盖 RPE → RIR、RIR → RPE、清除和保存原尺度四种操作。为旧偏好、双字段、仅力竭标记补读取 fixture。
2. 用 ADB 验证 0 与空值的区别，切换偏好后读回原历史，再显式保存并确认 API 只剩新尺度。验收并行修改其他组后，评分更正只影响目标组。
3. 执行 [共用验收](README.md#共用验收)，在迁移清单分别记录 RPE 与 RIR 的验收结果。
