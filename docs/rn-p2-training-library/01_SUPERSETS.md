# 01 超级组

## 需求

用户可在编辑计划时组合相邻动作，为组设名称和轮间休息。训练中可在相关动作记组前组合或拆分，完成一轮后休息，历史能看出哪些动作属于同一组。

1. **组队与顺序**。在计划并入两个相邻动作，设置 A 两组、B 一组；开始训练后按 A1 → B1 → A2 推进。热身先记，做完的成员从后续轮次跳过。
2. **休息与恢复**。A1 → B1 切换时不启动轮间休息；B1 完成后才启动。组设 73 秒时按 73 秒计，未设置时采用成员中最长的休息设置。训练全部完成时结束计时。切后台和强制停止后可继续正确的下一组。
3. **记录与同步**。计划保存重开后组关系一致，记组前替换动作仍留在原组，其实际动作 ID 与组 ID 可从训练历史和服务器读回。

## 实现设计

- 五入口版已有 [计划编辑](../../mobile-rn/src/screens/PlanEditorScreen.tsx)、[训练页](../../mobile-rn/src/screens/WorkoutScreen.tsx)、[统计历史](../../mobile-rn/src/screens/StatsScreen.tsx) 接线。优先复验这些入口，按实际差异修正。
- 沿用 [RN 轮转逻辑](../../mobile-rn/src/supersets.ts)、上游 `supersetUnits`、`restSecFor`。序列化保留计划 `sg/sgName/sgRest`、历史 `entry.sg` 及 `entry.target`，下一组由草稿中的完成状态计算。
- 高级组的降重段或短休分段属于一条正式组。后续接入时，只有整组记组才推进到超级组的下一成员。

## 执行步骤

1. 用 `five-tab-smoke.ps1` 核对导航，将 [旧回归](../../mobile-rn/scripts/android-regression.ps1) 的 `-SupersetChecks` 改为从「计划 → 训练计划 → 更多」进入训练或编辑，通过训练动作菜单操作组队，并从统计进入历史。
2. 在可见模拟器配对独立 API，执行需求 1–3。测 73 秒时用实时时钟，另测成员休息 25/40 秒时取 40 秒。读回 `sg`、组名、动作顺序和组数。
3. 用截图拼图确认计划、组队菜单、轮间休息和历史的布局。在迁移清单保留 `0.1.4` 旧验收，并补记新版复验结果。
