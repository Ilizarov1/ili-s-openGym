# 06 动作收藏

## 需求

用户可在动作库收藏或取消收藏内置、自定义动作。编辑计划、自由训练加动作、训练中替换动作时，也能在共用选择器用「仅收藏」快速查找。

1. **收藏与取消**。操作后星标立即更新，重复进入页面和重开 App 状态一致。自定义动作改名后仍按同一 ID 收藏。
2. **筛选**。打开「仅收藏」时，可继续组合中英文搜索、部位、器械筛选，结果和计数一致。没有匹配项时显示相应空状态，清除筛选后回到原列表。
3. **离线与同步**。本机练习与每个已配对账号各自保存。已配对时离线收藏或取消，重连后 Web 可读取，重试不会翻转状态或覆盖其他动作的收藏。

## 实现设计

- 复用 Web 的 `Profile.favEx` ID 列表和 [favourites.js](../../frontend/src/lib/favourites.js) 读取/排序。旧数据缺字段按空列表处理。新增待同步操作写「动作 ID + 最终是否收藏」，重放时增删指定成员，通过当前 [服务器冲突重试](../../mobile-rn/src/server.ts) 应用到最新状态，由 [上游同步戳](../../api/sync-stamps.js) 维护取消和重新收藏语义。
- [动作库](../../mobile-rn/src/screens/ExerciseLibraryScreen.tsx) 复用 `IconButton`、`Chip` 和筛选 `Sheet`。新增入口经 `App.tsx` 回调进入 `useGym.commit`，各选择场景共享状态。内置动作在 [目录查询](../../mobile-rn/src/catalogue.js) 分页截断前完成收藏筛选和排序，查询结果与计数采用同一条件。
- 收藏只取当前可见且仍存在的动作。Web 删除自定义动作后的残留 ID 不显示在收藏结果，计划按现有动作选择流程保存。

## 执行步骤

1. 接入工作区收藏状态和单动作同步操作，再加星标、筛选和空状态。用内置动作、自定义动作及当前首屏范围之外的收藏动作验证顺序和总数。
2. 在可见模拟器验证三个选择入口及账户隔离。用独立 API 制造 RN 离线取消 A、Web 同时收藏 B 的场景，重连后确认 A 已取消、B 已保留；再收藏 A 验证读回。
3. 执行 [共用验收](README.md#共用验收)，记录筛选截图、重启结果和服务端 `favEx`。

## 验收目标

| 编号 | 前置条件 | 操作 | 通过标准 |
| --- | --- | --- | --- |
| 1 | 有一个目录动作和一个自定义动作，均未收藏 | 收藏两项、改名自定义动作，关闭并重开 App | 两个星标仍亮，新名称沿原 ID 显示；取消任意一项后只少该项 |
| 2 | 一项已收藏目录动作位于默认分页之后；含两项部位相同、器械不同的收藏 | 打开「仅收藏」，组合中英文搜索、部位、器械和清空 | 分页之外的收藏可找到；匹配数量与列表一致；无匹配有提示，清空恢复原列表 |
| 3 | 已收藏动作存在且可用于训练 | 在计划加动作、自由训练加动作、训练替换中依次筛选并选择 | 三处使用同一收藏列表，选择后进入各自原流程 |
| 4 | 已配对的 A 收藏着动作 X，B 与练习模式没有 | RN 离线取消 X，Web 同时收藏 Y，重连两次 | A 资料的 `favEx` 无 X、有一个 Y；切到 B 或练习模式时按各自资料展示 |
| 5 | Web 已删除一个曾收藏的自定义动作 | 同步、查看仅收藏并重试恢复 | 已删除动作不出现在列表和计数，其他收藏及动作仍可选择 |
